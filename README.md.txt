# Vpanel

یک پنل مدیریت پیشرفته برای پیکربندی، مانیتورینگ و مدیریت سرورها، ترافیک شبکه‌ و کاربران.

## ویژگی‌ها
- ساخت و مدیریت یکپارچه کانفیگ‌های Xray (Vmess, Vless, Trojan, Shadowsocks)
- مانیتورینگ لحظه‌ای ترافیک کاربران و وضعیت سرورها
- ارائه داشبوردهای مجزا برای ادمین و کاربر
- پشتیبانی کامل از Docker جهت استقرار سریع

## پیش‌نیازها
- [Docker](https://www.docker.com/) و Docker Compose
- سیستم‌عامل لینوکس یا ویندوز

## نصب سریع با Docker (محیط سرور)
۱. ابتدا مخزن را دریافت کنید:
`git clone https://github.com/H0seinpik/Vpanel.git`
`cd Vpanel`

۲. فایل متغیرهای محیطی را آماده کنید:
`cp .env.example .env`

۳. پروژه را اجرا کنید:
`docker-compose up -d`

## اجرای سریع در ویندوز
برای راحتی بیشتر در محیط ویندوز، مجموعه‌ای از اسکریپت‌های خودکار آماده شده است. کافیست ابتدا فایل `install.bat` را برای نصب پیش‌نیازها و سپس `start.bat` را برای اجرای پنل باز کنید.
